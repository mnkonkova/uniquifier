# Уникализатор

Берёт папку готовых рилсов (например, партию «бот работ» `h1_t1_c1.mp4` …) и
делает из каждого свою версию, чтобы Instagram не счёл два ролика одним и тем
же. Потом сам проверяет результат тем же видео-хэшем, которым пользуется Meta.

## Как запустить

```bash
python3.12 -m venv .venv && .venv/bin/pip install -r requirements.txt
brew install chromaprint                    # один раз: звуковой отпечаток для проверки звука

.venv/bin/python uniquify.py capacity ПАПКА [ПАПКА…]   # сколько можно сделать уникальными
.venv/bin/python uniquify.py run ПАПКА [ПАПКА…] --name bot_уник --count 200 --threshold 10 \
    --levers рамка,скорость,тон --dry-run              # посмотреть план
.venv/bin/python uniquify.py run … (то же без --dry-run) # собрать + проверить
```

## Подача: три вопроса

1. **Сколько** — `--count N`. Уникализатор берёт до N роликов, которые можно
   развести до порога, начиная с тех, у кого меньше всего похожих соседей.
   `capacity` заранее показывает таблицу «порог × рычаги → сколько выйдет».
   `--allow-shared` добирает до N остальными (их, скорее всего, не пропустит гейт).
2. **Порог** — пара не проходит при > P% общих кадров. По умолчанию 30, меняется
   в `config.yaml → gate.fail_pct` или разово флагом `--threshold P`.
3. **Как** — `--levers` через запятую: `рамка`, `наклон`, `скорость`, `тон`
   (по умолчанию `рамка,скорость,тон`).

Замер на «бот работ» (450 роликов трёх партий):

| рычаги | обликов | ≤0% | ≤5% | ≤10% | ≤20% | ≤30% |
|---|---|---|---|---|---|---|
| скорость | 1 | 7 | 10 | 12 | 48 | 81 |
| рамка+скорость | 20 | 134 | 188 | 207 | 359 | 450 |
| +наклон ±0.5° | 22 | 149 | 203 | 223 | 367 | 450 |

## Любой формат, со звуком и без

* Размер и пропорции выхода — как у исходника: вертикальный остаётся 9:16,
  горизонтальный 16:9 не сплющивается (облики заданы в долях кадра).
  Частота кадров — тоже как у исходника.
* Видео без звуковой дорожки собирается без неё; проверка звука его пропускает
  и перечисляет отдельно.

## Профили рамки (`--profile`, `config.yaml → framing.profiles`)

Рамка — главный рычаг, и её запас зависит от того, что можно срезать:

| профиль | для чего | что можно срезать | обликов (замер) |
|---|---|---|---|
| `reels` (по умолчанию) | готовые рилсы | сверху до 7.8%, снизу до 12% (там интерфейс Instagram), титры защищены | 20 на «бот работ» |
| `raw` | сырое / не нарезанное видео | до 5% с каждой стороны, титры не защищаются | 6 на горизонтальном подкасте |

Прямоугольник титров в `reels` замерен по партии «бот работ» — для другого
материала замерьте свой или поставьте `text_box: null`. В `raw` поле 3% давало
0 обликов (рамка не уходит от оригинала), 4% — 4, 5% — 6, 6% — 9.

Несколько папок уникализируются вместе — облики раздаются по общему графу, и
ролики разных партий тоже расходятся между собой.

```bash
# ещё сравнить с уже выложенными:
.venv/bin/python uniquify.py run ПАПКА --name bot_уник --against output/уже_выложенные
```

Готовое — в `output/<name>/v1/` (каждый новый прогон — `v2`, `v3`…, `latest`
указывает на последний). Рядом лежат `plan.json` (что досталось каждому ролику)
и `dedup_report.json` (все пары с процентом совпавших кадров).

После гейта пары за порогом чинятся сами: один ролик из пары пересобирается с
другим обликом, и гейт повторяется (до 3 раз). Починить уже собранную версию:
`.venv/bin/python uniquify.py repair output/bot_уник/v1 ПАПКА [ПАПКА…]`.

Отдельно проверить любую папку: `.venv/bin/python qa_dedup.py ПАПКА [--against ДРУГАЯ]`.

## Что делается с каждым роликом

| Рычаг | Что | Насколько помогает (замер на «бот работ») |
|---|---|---|
| **Рамка** | приближение 5–14% + сдвиг окна | главный рычаг для картинки: сдвиг на 22–40 px → 0% совпавших кадров |
| **Скорость** | ±1–3%, голос не меняет высоту | картинка: 26–33% совпавших кадров; звук: 36% совпавших отрезков |
| **Тон** | высота голоса −3% или +3%, тембр сохраняется | главный рычаг для звука: 12% совпавших отрезков против оригинала, на слух не заметно |
| **Метаданные, GOP** | стираются / у каждого свой | на отпечатки не влияют |

**Шума нет намеренно.** На картинке шум 25% оставил 100% совпавших кадров, в звуке
шум даже на 6 дБ тише голоса (громко, мешает) — 91–97% совпавших отрезков.
Эквалайзер и эхо в звуке — тоже ~100%.

Тон — ступенями, а не плавно: звук двух роликов с общим хуком расходится только при
разнице ≥3% (один тон — 87% совпадений, разница 1% — 67–76%, 3% — 12–29%, 6% — 1–5%).
Самые похожие пары получают разные ступени.

Облики (рамка ± наклон) подбираются перебором под материал при каждом запуске
(`palette.py`, результат кэшируется): у любой пары обликов на выборке кадров нет
ни одного общего кадра, ни один не режет титры и не открывает чёрные углы (поля —
в `config.yaml → framing`). На «бот работ» выходит 20 обликов, с наклоном 22.

Кому какая рамка: уникализатор сначала сравнивает **исходники** между собой и
строит граф «кто на кого похож» — по кадрам, а не по именам (у «бот работ»
ролики делят ещё и мемы с кадром продукта, которых в имени нет). Похожие
ролики получают разные рамки. Если рамок не хватает, общую рамку получают самые
слабо похожие пары, и уникализатор пишет, какие.

## Гейт и пороги

Видео-хэш Meta **vPDQ** (открыт в ThreatExchange): кадр раз в секунду → 256-битный
PDQ-хэш → два ролика сравниваются по доле кадров, нашедших «двойника».

* кадры совпадают при расстоянии ≤ **31** бита из 256 (порог PDQ от Meta;
  у случайных кадров в среднем 128);
* почти однотонные кадры (качество PDQ < **50**) не сравниваются — как в vPDQ;
* Meta в примере называет ролики копией при ≥ **80%** совпавших кадров;
* **наш порог по умолчанию — 30%** (`config.yaml → gate.fail_pct`). Instagram
  свой порог не публикует; 30% — самый строгий порог, при котором на «бот работ»
  проходят все 450 роликов, и он почти втрое ниже примера Meta.

Официальный пакет `vpdq` на macOS не собирается, поэтому сравнение повторено в
`qa_dedup.py` поверх `pdqhash` (тот же эталонный PDQ).

Источники: [vPDQ README](https://github.com/facebook/ThreatExchange/blob/main/vpdq/README.md),
[PDQ & TMK+PDQF — разбор](https://arxiv.org/abs/1912.07745).

## Звук

`qa_audio.py` — открытый звуковой отпечаток Chromaprint (AcoustID). Как звук
сравнивает Instagram, не публикуется; это лучший открытый аналог. Проверяется
каждый новый ролик против своего оригинала и пары новых роликов с общим куском.
Порог — `config.yaml → gate.audio_fail_pct` (по умолчанию 30%).
